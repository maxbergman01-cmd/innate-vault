Project A1 • Operational Foundation

Smart PLM Backbone (Pilot)

Replacing fragmented Excel sheets with a cloud-native 'Single Source of Truth' for the Outerwear category.

The Problem

Product data currently lives in "dark silos"—individual desktops, email chains, and WhatsApp messages. There is no single source of truth for Tech Packs, BOMs, or measurement specs.

  • Version Control: Factory often works off outdated specs (v2 vs v5).
  • Redundant Entry: Data is re-typed 4x per style across different trackers.
  • Blind Spots: No aggregate visibility on fabric liability or component usage.

High-Level Solution

A lightweight, cloud-native PLM (Product Lifecycle Management) backbone built on AirTable/Softr, acting as the master database for the Outerwear category.

  • One Master Record: Updates flow instantly to all PDF outputs.
  • Automated Tech Packs: "One-click" generation of factory-ready PDFs.
  • Supplier Portal: Factories log in to see live specs (no more email attachments).

Implementation Plan (12 Weeks)

• Data Audit: Review all current Excel templates (Tech Pack, BOM, Critical Path) to map every data field (approx 45 fields).

• Schema Build: Define relational structure: Style -> Colorway -> SKU -> Component -> Supplier.

• Standardisation: Cleanse drop-down lists for Colors, Fabrics, Trims, and Size Ranges to ensure data integrity.

• Ingestion: Import last 2 seasons of Outerwear data (150 styles) to populate the component library.

• PDF Engine: Configure "Page Designer" block to replicate the exact factory PDF layout (pixel perfect).

• Automation Logic: Set up triggers (e.g., When status = "Approved", email PDF to Factory Contact).

• Parallel Run: Execute 2 live styles in both Excel and New System to validate outputs.

• Training: Interactive workshops for 4 key users (Designer, Garment Tech, PD, Merch).

• Go-Live: Lock Excel folders for new Outerwear styles. Support hotline open.

Financial Impact Analysis (Year 1)

Benefit Driver Calculated from stated assumptions
Admin Efficiency £53,040
Assumption Model:
• Headcount: 4 Senior Designers @ £65k/yr fully loaded.
• Current State: Time study reveals 22% of weekly hours spent on data entry/admin.
• Future State: Automation reduces this to 5%.
• Calculation: 0.17 × 4 × £65,000 × 1.2 (overhead) = £53,040. PM efficiency gains are not quantified and are excluded.
Error Reduction £23,400
Assumption Model:
• Sample Cost: Avg Landing Cost per Sample (Air + Duty): £450.
• Rejection Rate: Current: 28% due to spec errors. Target: 15%.
• Volume: 400 new styles/yr.
• Calculation: 400 × (0.28 − 0.15) × £450 = £23,400. Reduced courier fees are not quantified and are excluded.
Freight Avoidance £12,500
Assumption Model:
• Air Ratio: Current: 18% of volume shipped by Air. Target: 8%.
• Cost Delta: Avg Air Premium vs Sea: £2.50/unit.
• Volume: 50,000 units impacted in Outerwear category.
• Calculation: 50,000 × (0.18 − 0.08) × £2.50 = £12,500 gross savings.
